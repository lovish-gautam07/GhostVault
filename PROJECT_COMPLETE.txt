📋 PROJECT OVERVIEW
════════════════════════════════════════════════════════════════════

GhostVault is a complete full-stack encrypted digital legacy and
emergency access manager with a "dead man's switch" system.

Core Concept:
- Users store sensitive data (passwords, notes, documents)
- Data is encrypted client-side with AES-256-GCM before upload
- If user becomes inactive for X days, data auto-releases to
  designated emergency contacts
- Periodic "check-ins" reset the dead man's timer

🚀 HOW TO RUN
════════════════════════════════════════════════════════════════════

Method 1 - Automated Setup (Recommended):

  chmod +x install.sh
  ./install.sh

  Then open two terminals:
  Terminal 1: npm run dev:backend
  Terminal 2: npm run dev:frontend

  Visit: http://localhost:3000

Method 2 - Manual Setup:

  # Backend
  cd backend
  npm install
  npx prisma generate
  npx prisma db push
  cd ..

  # Frontend
  cd frontend
  npm install
  cd ..

  # Run
  npm run dev:backend    # Terminal 1
  npm run dev:frontend   # Terminal 2

Method 3 - Run Tests:

  cd backend
  npm test

🎓 USAGE FLOW
════════════════════════════════════════════════════════════════════

1. User signs up with master password
2. Master password derives AES-256 key client-side
3. User adds trusted emergency contacts
4. User creates vault items (encrypted in browser)
5. User assigns items to contacts with release tiers
6. User checks in periodically (manual button)
7. If inactive > tier days:
   → Cron job detects inactivity
   → Creates release records
   → Sends emails to contacts
   → Contacts receive encrypted item access
